# Experimento Tinder — V4 final

## Cambios de esta versión
- Menos espacios vacíos en los perfiles.
- Panel derecho más compacto.
- Green Flags y Red Flags con altura ajustada al contenido.
- Última actividad integrada inmediatamente debajo.
- Navegación inferior más pequeña.
- Caras corregidas en la pantalla de conclusiones.
- Miniaturas más altas y mejor centradas.
- Animación suave al cambiar de diapositiva.

## Cómo ejecutar
1. Abre la carpeta `tinder_presentacion_v4` en VS Code.
2. Confía en la carpeta si aparece Restricted Mode.
3. Abre `index.html`.
4. Clic derecho → `Open with Live Server`.

## Controles
- Flecha derecha o barra espaciadora: avanzar.
- Flecha izquierda: retroceder.
- Botones inferiores: navegación.
